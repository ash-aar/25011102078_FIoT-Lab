# CAT5 – Timer, Waveform and Stepper Motor Experiments

This category contains experiments involving timer-based operations, waveform generation and stepper motor interfacing using the 8051 microcontroller.

## Experiments

### TASK5A – LED Fading

Implements LED fading using timer interrupts and software-based PWM control.

[View TASK5A](TASK5A/)

### TASK5B – Square Wave Generation

Generates a square wave by periodically toggling an output pin.

[View TASK5B](TASK5B/)

### TASK5C – Stepper Motor Control

Controls a four-phase unipolar stepper motor using a predefined full-step sequence.

[View TASK5C](TASK5C/)

## Learning Outcomes

- Understand timer-based operations in the 8051 microcontroller.
- Implement periodic operations using timer interrupts.
- Generate square wave signals through GPIO toggling.
- Understand the phase sequence used to control a stepper motor.
